# Customer and Product Analysis Dashboard | Power BI

## 📌 Project Overview

This project is an interactive Power BI dashboard developed to analyze customer distribution across cities and product distribution across categories. Using the `AdvLT2017_temp1.xlsx` dataset, the dashboard presents customer and product information in a clear, organized, and visual format.

The project demonstrates how Power BI can transform raw Excel data into meaningful insights through data modeling, visualizations, and interactive reports.

## 🎯 Project Objectives

- Analyze the number of customers in each city.
- Display city-wise customer lists and their information.
- Analyze the number of products in each category.
- Display category-wise product lists and their details.
- Present business data through interactive Power BI visualizations.

## 📂 Dataset

**Source file:** `AdvLT2017_temp1.xlsx`

The dataset serves as the source for customer, product, category, and related business information.

The analysis uses relevant fields such as:
- Customer ID and customer name
- City and location
- Product ID and product name
- Product category
- Product specifications and pricing

## 📊 Dashboard Features

### 1. City-Wise Number of Customers
Displays the number of customers in each city, helping identify cities with higher customer representation.

### 2. City-Wise Customer Details
Provides a detailed list of customers organized by city, including available customer and location information.

### 3. Category-Wise Number of Products
Shows the number of products available in each category, making it easier to compare product distribution.

### 4. Category-Wise Product Details
Displays product information grouped by category, including available product names, specifications, and prices.

## 📈 Key Insights

The dashboard helps users:
